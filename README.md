## ✨ ویژگی‌های کلیدی

- **تخصیص هوشمند پس‌انداز**: دریافت درآمد یا سرمایه کل ورودی و اختصاص ۳۰٪ آن برای پس‌انداز (قابل شخصی‌سازی).
- **تقسیم پایه طلا و کریپتو**: تقسیم مبلغ پس‌انداز به **۸۰٪ طلا** و **۲۰٪ ارزهای دیجیتال** (قابل تنظیم).
- **سبد رمزارز پیش‌فرض (مطابق جدول هدف)**:
  - اتریوم (ETH): ۲۵٪
  - بیت‌کوین (BTC): ۱۹٪
  - بایننس‌کوین (BNB): ۱۵٪
  - کاردانو (ADA): ۹٪
  - پولکادات (DOT): ۹٪
  - ترون (TRX): ۸٪
  - ریپل (XRP): ۸٪
  - دوج‌کوین (DOGE): ۵٪
  - پولیگان (POL): ۲٪
- **الگوریتم بازتنظیم سبد (Portfolio Rebalancing)**: خریدهای جدید طوری بین دارایی‌ها پخش می‌شوند که با احتساب موجودی‌های قبلی کاربر، کل ارزش سبد دقیقاً به درصدهای هدف برسد.
- **بخش اختصاصی خرید طلا**: محاسبه ارزش تومانی + تبدیل خودکار به **گرم و سوت** با توجه به نرخ روز طلای ۱۸ عیار.
- **جدول خریدهای پیشنهادی با کپی ۱-کلیک**: کپی سریع مبالغ جهت ثبت آسان سفارش در صرافی‌های ایرانی (نوبیتکس، والکس، تبدیل، و...).
- **دکمه اعمال خریدها به موجودی**: افزودن خریدهای انجام‌شده به دارایی‌های فعلی با یک لمس به همراه ثبت تاریخچه تراکنش‌ها.
- **کارکرد ۱۰۰٪ آفلاین و دائمی**: ذخیره تمامی داده‌ها روی `localStorage` دستگاه بدون ارسال به هیچ سرور خارجی.
- **خروجی بومی اندروید (Capacitor Android)**: بدون نیاز به روشن بودن کامپیوتر یا مرورگر.

## 🧮 فرمول و منطق محاسباتی

### ۱. تفکیک سرمایه ورودی:
$$\text{Total Savings} = \text{Input Amount} \times \frac{\text{Savings \%}}{100}$$

$$\text{Gold Budget} = \text{Total Savings} \times \frac{\text{Gold \%}}{100}$$

$$\text{Crypto Budget} = \text{Total Savings} \times \frac{\text{Crypto \%}}{100}$$

### ۲. الگوریتم بازتنظیم هوشمند (Waterfilling Rebalancing):
برای هر ارز $i$ با وزن هدف $w_i$ و موجودی فعلی $C_i$:
1. مجموع ارزش نهایی کریپتو: $T = \sum C_i + \text{Crypto Budget}$
2. ارزش هدف هر ارز: $Target_i = T \times w_i$
3. مبلغ خرید پیشنهادی خام: $Buy_i = Target_i - C_i$
4. اگر موجودی یک ارز بیش از وزن هدف باشد ($Buy_i < 0$)، سهم خرید آن صفر شده و بودجه به سایر ارزهای کم‌وزن تخصیص می‌یابد تا سبد بدون نیاز به فروش به توازن برسد.

## 🛠️ استک فنی و تکنولوژی‌ها

- **هسته و رابط کاربری**: React 18 + TypeScript + Vite 6
- **طراحی و استایلینگ**: Tailwind CSS (با تم لوکس دارک متالیک و لایت شفاف)
- **آیکون‌ها و المان‌ها**: Lucide React
- **نمودارها**: Recharts (نمودار دونات تعاملی)
- **موبایل و بیلد بومی**: Capacitor 7 (Android Native Platform)
- **کش آفلاین PWA**: Vite Plugin PWA (Workbox Service Worker)
- **اتوماسیون ابری**: GitHub Actions (Java JDK 21 + Gradle Build)

## 📥 نحوه دریافت و نصب فایل APK اندروید

### روش ۱ (پیشنهادی): دریافت فایل نصبی از GitHub Actions / Releases

1. این پروژه را روی مخزن گیت‌هاب (GitHub) خود قرار دهید:
   ```bash
   git init
   git add .
   git commit -m "Initial release"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```
2. وارد مخزن خود در سایت گیت‌هاب شوید و روی تب **Actions** بزنید.
3. گردش‌کار **Build & Release Android APK** را انتخاب کنید و روی **Run workflow** کلیک کنید.
4. پس از ۱ الی ۲ دقیقه، وارد تب **Releases** در صفحه اصلی مخزن شوید و فایل **`Investment-App-v1.0.0.apk`** را مستقیماً دانلود و روی گوشی خود نصب کنید!

---

### روش ۲: ساخت APK با Android Studio در کامپیوتر

اگر نرم‌افزار Android Studio روی ویندوز شما نصب است:
1. دستور زیر را اجرا کنید:
   ```bash
   npm run cap:open
   ```
2. پس از باز شدن پروژه در Android Studio، از منوی بالا مسیر زیر را انتخاب کنید:
   `Build > Build Bundle(s) / APK(s) > Build APK(s)`
3. فایل APK ساخته‌شده در مسیر `android/app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## 📲 نحوه نصب PWA روی آیفون و اندروید

### در آیفون (iOS Safari):
1. لینک برنامه را در مرورگر **Safari** باز کنید.
2. دکمه **Share** (آیکون اشتراک‌گذاری در پایین) را لمس کنید.
3. گزینه **Add to Home Screen** (افزودن به صفحه اصلی) را بزنید و سپس **Add** را انتخاب نمایید.

### در اندروید (Chrome):
1. لینک برنامه را در مرورگر **Chrome** باز کنید.
2. روی منوی ۳ نقطه در بالا سمت راست بزنید و گزینه **Install app** یا **Add to Home screen** را انتخاب کنید.

## 💾 پشتیبان‌گیری و امنیت اطلاعات

- تمامی داده‌ها (موجودی دارایی‌ها، درصدهای تنظیم‌شده و تاریخچه تراکنش‌ها) در **حافظه محلی مرورگر / وب‌ویو گوشی (`localStorage`)** ذخیره می‌شوند.
- **حفظ حریم خصوصی**: هیچ‌گونه اطلاعاتی به سرورهای خارجی ارسال نمی‌شود.
- **خروجی فایل پشتیبان**: در بخش تنظیمات برنامه می‌توانید با زدن یک دکمه، کل اطلاعات خود را در قالب یک فایل `JSON` دانلود کرده و در دستگاه‌های دیگر بازیابی کنید.

## 🔧 رفع اشکال (Troubleshooting)

### خطای `invalid source release: 21` در GitHub Actions:
این خطا به دلیل عدم تطابق نسخه جاوا با گرادل Capacitor 7 رخ می‌دهد. در فایل `.github/workflows/build-apk.yml` نسخه جاوا روی **JDK 21** تنظیم شده است که مشکل را به طور کامل برطرف می‌کند.

### عدم بارگذاری آفلاین در حالت Dev:
در حالت توسعه (`npm run dev`) به دلیل مکانیزم Hot-Module-Replacement فایل‌ها کش نمی‌شوند. برای تست عملکرد آفلاین، حتماً از نسخه بیلدشده با دستور `npm run build` یا فایل نصبی APK استفاده کنید.
